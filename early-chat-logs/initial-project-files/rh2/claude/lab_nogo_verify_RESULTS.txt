==============================================================================
  p = z^2+1, T_0 = companion, T_1..3 = 0, lambda = 0, C = T_0^2
    T_0 = [[0.0, -1.0], [1.0, -0.0]],  C = [[-1.0, 0.0], [0.0, -1.0]]
    tr C = tr T_0^2 + tr T_e^2 ?   -2.000000 = -2.000000 + 0.000000   -> HOLDS
    kappa = tr T_a^2 = 0, lambda = 0                              -> HOLDS
    T_1 = T_2 = T_3 = 0                                           -> HOLDS
    C = T_0^2 ?  max diff 0.0e+00                            -> HOLDS
    eigenvalues of T_0 are REAL ?  eig = [1j, (-0-1j)]        -> **FAILS**

  Every step of memo7 §4.4 survives except the last, which is exactly the
  spectral theorem for real symmetric matrices.
