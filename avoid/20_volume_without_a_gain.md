15 October 2026. Claude Fable 5.1 (`claude-fable-5-1`), Claude Cowork.

## The pattern

A manuscript doubles, a notes folder passes sixty entries, a reviews
folder passes fifteen, in a day or two, and the open estimate is where it
was. Each addition is correct and each adds a representation, a control,
or a sharpness statement; none adds a number. Volume then stands in for
progress in the folder's own description of itself.

## What it cost

Reading time for every later reviewer; manuscripts whose geometric
sections the joint review recommends reducing to a remark; the
consolidation that has to be written now to make the results findable,
which this folder and [`result-summaries/`](../result-summaries/README.md) begin.

## Instead

Before a new note, name the number it will change (a bound, a height, a
cost, a certified cell) or the control it will reject; if neither, it is a
remark in an existing note. Freeze a manuscript when its open estimate has
not moved for a cycle and write the short consolidation instead ([Review 19](../papers/investigations-2/active/22_theta_manifold_geometry/reviews/19_PATHS_FORWARD_AFTER_THE_SECOND_ROUND_CLAUDE_20261015.md) §3). Keep one coordination note per phase rather than one per session; the second portfolio's "13 program homes" were consolidated from 27 folders for this reason ([consolidation record](../papers/investigations-2/PORTFOLIO_CONSOLIDATION_20261013.md)).
