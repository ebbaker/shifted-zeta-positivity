# Weil-positivity line

16 October 2026. Prepared for Edward Baker with LLM assistance (Claude Opus
5.5, configured identifier `claude-opus-5-5`, Claude Cowork, reasoning effort
max).

This folder holds the repository's first line of work, August and September
2026. Its RH-directed target is the complete central Weil form:
$Q_{0,L}[f]\geq0$ for every support length $L>0$ and every smooth compactly
supported input $f$, with the gamma, pole and prime terms kept together (the
normalizations are in the [SUSY-positivity background](susy-positivity/background.pdf)).
The all-length sign problem remains open; no RH proof is claimed.
