The conjecture is that the finite Schur response matrix S_{n,N} is positive semidefinite for every positive integer interval length n and every admissible cutoff N; equivalently, one admissible cutoff at each length suffices. The certified search is an optional implementation. The draft supplies the equivalence proof and unconditional boundary/remainder estimates, including an image expansion with an exponential remainder bound. It does not prove the conjecture. The present smallest admissible cutoff grows doubly exponentially with length. The numerical length-one example illustrates small spectral margins in upper approximations and supplies no positivity certificate.
