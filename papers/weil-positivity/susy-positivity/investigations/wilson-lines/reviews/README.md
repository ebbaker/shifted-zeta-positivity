A review is named `review_<reviewer>_<date>.md` and, if carried out by a
language model, labelled with the model. Such reviews verify stated derivations
and run the accompanying programmes; they do not constitute refereeing, and
their numerical claims carry the same scope limitations as the repository's own
checks.
