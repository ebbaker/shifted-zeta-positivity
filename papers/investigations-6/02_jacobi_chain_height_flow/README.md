OpenAI Codex LLM assistance. Actual backend model and effort are unavailable
in recorded configurations.

Explore the exact infinite chain that generates a continuous family of Newman wavefunctions across height and imaginary time. The main questions concern recursive amplitudes, propagation through polynomial-degree sites and the signed return amplitude.

This branch owns the fixed-basis Jacobi evolution and its single-excitation MPS. Branch 03 owns the moving recurrence coefficients; branch 04 owns source-scale products.

The [research overview](research-overview/01_JACOBI_CHAIN_RESEARCH_OVERVIEW_20261113.md) gives the fixed
source, inherited identities, mathematical domains, evidence and open
questions. See the [program overview](../research-overview/01_TENSOR_NETWORK_PROGRAM_OVERVIEW_20261113.md)
for the common purpose and relationships among all four branches.

The [14 November analytical manuscript](manuscript/README.md) derives
the fixed chain, its single-excitation realization and the scalar error
and sufficient depth with exact coefficients. It includes the existing
16-site certificate as a finite illustration of coefficient and rounding
uncertainty. See the [source map](notes/03_JCH_ANALYTICAL_MANUSCRIPT_INTEGRATION_20261114.md)
and [internal assessment](reviews/02_JCH_ANALYTICAL_MANUSCRIPT_ASSESSMENT_20261114.md).

The finite principal chain has a [proved absolute scalar error bound](notes/02_JCH_E01_R1_FINITE_CHAIN_READOUT_20261113.md)
and an explicit sufficient depth on every bounded real-height rectangle.
Its direct Gaussian-quadrature baseline gives identical scalar values.
The [same-worker assessment](reviews/01_JCH_E02_FINITE_CHAIN_ASSESSMENT_20261113.md)
checks the result within its original domain, with numerical enclosure and
relative lower margins still open. The [branch plan](research-plan/01_JACOBI_CHAIN_RESEARCH_PLAN_20261113.md)
defines the tasks and the [sole JCH register](research-progress/01_JACOBI_CHAIN_RESEARCH_PROGRESS_20261113.md)
owns status. The [collection plan](../research-overview/02_TENSOR_NETWORK_RESEARCH_PLAN_20261113.md)
and [TN6 register](../research-progress/01_TENSOR_NETWORK_RESEARCH_PROGRESS_20261113.md)
own the shared interface. The exact chain and bond-two encoding are
inherited representation identities with same-assistant checking.
