The first candidate, a divided difference of the originally bounded analytic cubic residual, already saves a factor of order \(\ell\) at fixed nonzero \(q/\ell\) by Cauchy on a larger fixed disk. Reproducing that saving would leave the range unchanged. Select the second candidate. Pay the Gaussian-relative error on a disk growing like \(\sqrt{\log\kappa}\) in standardized Fourier frequency. Use a fixed smaller fraction for the inverse, so the count and remainder hold simultaneously for all adjacent retained indices. A comparison with the direct phase using exactly this growing-disk estimate is mandatory. Classification is a quantified large-time location estimate.
