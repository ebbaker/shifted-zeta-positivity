This branch of [arithmetic gap continuation](../README.md) starts with the [explicit large-time zero formulas](../brainstorm/notes/08_SUMMING_THE_LARGE_TIME_ZERO_LOOP_20261120.md). Its first question is which zeros each expression locates, with what proved error, and whether a sharper formula can control more of the divisor at a common upper time. Those locations supply the exterior interaction for each marked pair. The parent calls the generalized moments \(P^{(n)}_{p,q}\). The gap is predicted from \(M_n=P^{(n)}_{1,1}\) through \(g_n'=4/g_n-2g_nM_n\). The aim is a backward estimate with a stated time range and error that remains useful at arbitrary height.
