Prepared for Edward Baker with LLM assistance. Model: GPT-6 (Codex); exact serving variant and reasoning effort were not exposed.

These bounded floating calculations use X=13 and N=32,64. The spaces are independently generated by the analytic Xi kernel and its second and fourth derivatives. No zero list or ground eigenvector is used to construct them. Read the [diagnostic](../../reviews/CCM_DERIVATIVE_CLUSTER_DIAGNOSTIC_20260928.md) and [analytic continuation](../../notes/CCM_BOUNDARY_SELECTION_AND_COMPLEMENT_20260928.md) for interpretation and limitations.

With Python and mpmath 1.3.0 installed, run from this directory:

```sh
python3 -B check_derivative_cluster.py --repo-numerics .. --digits 130 --cutoffs 32 64 --output fresh-130.json
python3 -B check_derivative_cluster.py --repo-numerics .. --digits 160 --cutoffs 32 64 --output fresh-160.json
python3 -B summarize_derivative_cluster.py --repo-numerics ..
```

The last command verifies and summarizes the saved historical records; it performs no eigensolve. Use its `--record-a`, `--record-b`, and `--output` options when comparing fresh runs. The generator source was not changed after the recorded runs.
