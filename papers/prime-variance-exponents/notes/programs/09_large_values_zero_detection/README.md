## Exact target

Find a signed product/source estimate yielding one fixed saving, or a new amplification lemma excluding every forbidden zero. Positive-power density bounds allow isolated zeros.

## First deliverable and proposed mechanism

Match one Guth–Maynard primary theorem to actual coefficients, lengths, frequency windows and shell kernel. Any regrouping must include remainder/low-frequency costs. Trace what a single hypothetical zero forces before asserting amplification.

## Failure criterion

The direct current lengths exceed even \(T\), missing Theorem 1.1 near \(N<T^{10/11}\) and Proposition 12.1 for \(T^{5/6}\leq N\leq T\). One exceptional large value does not contradict density. Stop at range mismatch, uncharged exceptions or a circular zero-free input.
