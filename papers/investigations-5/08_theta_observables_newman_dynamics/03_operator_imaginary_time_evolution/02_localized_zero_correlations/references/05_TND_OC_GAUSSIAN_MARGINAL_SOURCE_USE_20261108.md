# Source use for the Gaussian marginal program

8 November 2026. Prepared for Edward Baker with substantial OpenAI Codex
LLM assistance; actual recorded model/effort unavailable, chat0003.

The existing parent bibliography record `Borodin2009DPP` is reused. The
primary reading is Alexei Borodin, *Determinantal point processes*,
[arXiv:0911.1153v1](https://arxiv.org/pdf/0911.1153v1), 6 November 2009.
Selected passages re-inspected on 8 November 2026: §2, equation (2.1),
correlation measures defined by distinct-point sums; equation (2.2),
the additional determinantal property; §4, Theorem 4.1, its extension
to a reference measure, and the circular Fourier-basis example.

Use: standard factorial-measure convention and determinant-product
ensemble benchmark. The manuscript explicitly derives the finite circular
two-coordinate marginal by Fourier orthogonality and the Gaussian
difference convolution. It does not import a determinantal representation
for canonical theta zeros, a local universality theorem, or a conclusion
about nonreal zeros. Labels extend the bookkeeping to multiplicities
before observation smoothing. The auxiliary independent observation law
and the source-transfer theorem are derived in Note09/manuscript, not
attributed to Borodin.

No new bulk PDF was placed in the repository. The already available
canonical bibliography is unchanged; the build selector now includes
this existing key. Earlier source/import audits and frozen E04 sources
are unchanged.
