This investigation asks which quantitative estimates from the complete theta
source or primitive can constrain a specified zero collision. It begins
with the event and the bound it needs. It does not require the generalized
marginal program to succeed first.

[OC program-fit review](../02_localized_zero_correlations/notes/14_TND_OC_B08_ARITHMETIC_MARGINAL_COLLISION_FRICTION_20261108.md).

independent, high-risk research program. The existing
[Green investigation](../01_green_potential_resolvent/README.md) retains its
own work and provides a direct comparison, not a task to duplicate here.
