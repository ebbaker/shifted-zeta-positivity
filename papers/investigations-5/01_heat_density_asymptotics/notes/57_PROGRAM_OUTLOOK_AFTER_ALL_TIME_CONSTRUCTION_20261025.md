## What has changed

The program now has a finite analytical construction on the intended
unbounded time/height domain. Note54 supplies the last positive attachment
and explicitly covers the long central interval preceding it. There is
one actual field prescription, one source per chosen accuracy, one
physical regulator and one fixed averaging kernel. Both infinite-time
limits refer to errors of this same construction. This is a substantive
coverage result even though the sufficient parameters are enormous.

The proof also identifies why the new joins are compatible with the
observable equations. They are made at the field; their heat and
nonholomorphic defects are retained; the signed stress is simplified
before absolute estimates; covariance subtracts the actual filtered
means. A collection of separately accurate density curves would not
provide that result.

Note55 then changes the source-cost mechanism. The earlier construction
used the smallest regulator over an expanding core, which imposed a
quadratic exponent in the joining radius. The new proof uses that floor
only in a fixed central region, where possible multiple zeros are allowed.
Farther out it uses the canonical field's already proved collars and
compares the source approximation directly to that field. The remaining
relative precision is set primarily by the decaying gamma carrier.

For the specified policy, at fixed upper time b and fixed targets,

    log(1/epsilon) = pi R/8 + O_b,eta,theta(log^2 R),
    log(source cells), log(explicit descriptor bound)
                  = pi R/32 + O_b,eta,theta(log^2 R).

The coefficient 1/4 in the latter expression comes from fourth-order
cubic approximation. It is not an invariant of the theta problem. The
current sufficient source size is still exponential in R; the result is
an improved construction bound, not a lower complexity bound.

These conclusions establish neither an affordable global evaluator nor
a collision exclusion. Fixed-regulator, fixed-filter absolute errors do
not resolve the unregularized zero measure automatically. Generic parts
of the transfer also hold for smooth colliding controls; canonical
completion and source estimates distinguish their application here.

## The strongest next task: compress the source with a complete proof

**Analysis — Sol: execute the existing
[HDA-17-AN05 r1](../research-progress/handoffs/HDA-17-AN05.md).** Its scope
already matches the new question, so no duplicate packet or new execution
is needed. Start with [95,97] and then state the dependence on an already
fixed b. Keep the exact IC14/IC23 tolerance and the complete four-jet

The uniform low-order cubic mesh pays for very high precision by making
many small cells. A positive analytic approximation could trade cells
for degree. The proposed p_n^2 source is attractive because positivity
would survive coefficient storage, while Gaussian polynomial moments
still give an exact-heat field. But the square root must first have a
quantitative analytic branch near the entire real source interval.

One concrete first estimate is to factor the unchanged complete source:

    Phi(u) = pi exp(5u) [2pi exp(4u)-3] exp[-pi exp(4u)] [1+R(u)],

    R(u) = sum_(n>=2) n^2 [2pi n^2 exp(4u)-3]
                  /[2pi exp(4u)-3]
                  * exp[-pi(n^2-1)exp(4u)].

The packet can try to prove, on an explicit complex neighborhood of
[0,U], that the leading factor has no zero and |R(u)|<1 with a uniform
margin. It must include a small left extension near zero, a positive
lower bound for Re exp(4u), the denominator bound and the full n>=2
tail. Those facts would give an analytic square root and a norm bound.
Real positivity by itself supplies none of these quantitative inputs.
No such neighborhood or margin is asserted by this outlook.

If an analytic strip of known width and norm is established, its polynomial
approximation rate can be turned into a finite degree and precision.
For any candidate approximation p to sqrt(Phi), the elementary consumer is

    |p^2-Phi| <= |p-sqrt(Phi)| [2|sqrt(Phi)|+|p-sqrt(Phi)|].

It must then be integrated against the same u^j exp(bu^2+4u), j<=3,
including the full tail. Coefficient conversion, coefficient rounding,
positivity and mode evaluation require separate debits. A favorable
formal approximation rate without these payments is only a partial
result. It would also be legitimate to return a different positive
representation or the first exact unpaid analytic input.

The decision metric is the final sufficient descriptor bound for the
same four-jet error, not approximation degree in isolation. Any claim
polynomial in R must retain all constants and specify whether b is fixed.
High-degree cancellation and evaluation precision remain a separate task
even if source storage improves dramatically.
