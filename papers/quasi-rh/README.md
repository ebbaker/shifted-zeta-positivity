# Quasi-RH line

This folder holds the second line of work, 3–11 October 2026. Its starting
point, proved in [prime-variance-exponents](prime-variance-exponents/README.md),
is that for each $\delta\in[0,1]$ the variance bound
$\mathcal V_g(X)=O(X^{2+\delta})$ for one prepared prime response holds
exactly when every nontrivial zero of zeta lies in the closed strip
$|\Re\rho-1/2|\le\delta/2$. Quasi-RH means the least admissible exponent is
below one, and RH means it is zero. The line asks whether a fixed zero strip
can be pushed to RH. It has not established a new unconditional zero-free
strip, Newman bound or route to RH.
