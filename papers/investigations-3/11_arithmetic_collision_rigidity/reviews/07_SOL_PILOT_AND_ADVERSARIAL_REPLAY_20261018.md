## Checks and limits

- The strengthened manuscript input matches the Stage 0 pin. Completion and
  reflection precede arithmetic truncation. All 77 midpoint jets and the
  two shifted majorant integrals are charged.
- The real-source comparator uses the same time strips, accuracy contract
  and resource limits. The original boundary/winding pilot is separately
  replayed, with identical polygon and segment hashes. A costly artificial
  two-dimensional baseline is not introduced.
- Every accepted interval contains the exact dyadic polynomial plus the
  listed physical approximation errors. Arithmetic remains outward in the
  polynomial enclosure; its midpoint is not silently treated as a point
  value with only the smaller added-error budget.
- Mode, cutoff, quadrature and Taylor payments are all present. Derivatives
  needed by time propagation are covered through order 78. Gamma-envelope
  comparisons do not assume a lower bound on H.
- The same strict interface rejects three-square, four-square, reflected,
  q_{T,a} and polynomial surrounding event boxes under their own source
  contracts. The Euler negative-Laguerre witness is separately labelled.
  Non-effective analytic controls retain that status.
- The native zero-centred-square failure stopped the run. The explicit
  outward square repair was applied to both the candidate and control
  interfaces, and all affected computations were rerun.

The [adversarial replay][replay] independently recalculates the saved signed
cells using the real-source branch at 256 bits. It also tests domain errors,
strict equality, malformed and missing inputs, changed witness bytes and

The result is a validated bounded tool and a measured propagation-error
