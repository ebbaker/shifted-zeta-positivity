set of project proposals, their dependencies, records and conventions.

`reviews/` folder; reviews that compare projects, propose changes to the
[portfolio plan](../research-overview/01_PORTFOLIO_RESEARCH_PLAN_20261016.md)
or audit the portfolio's records belong here. Each review states its model
and effort, whether it is same-model or cross-model, the commit it reviewed,
and the files it proposes to change; it does not change them.
