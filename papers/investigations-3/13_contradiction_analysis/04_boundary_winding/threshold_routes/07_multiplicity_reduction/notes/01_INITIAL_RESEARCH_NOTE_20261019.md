## Proposed reduction and its burden

For an exact m-fold zero, \(F=\partial_x^{m-2}H\) has a double zero at the same point and still solves backward heat. This algebra does not make F the canonical theta function. Its source changes, and an odd number of derivatives also changes its parity. A fixed-function arithmetic theorem for H cannot simply be applied to F.

A valid reduction must identify the class of functions for which the double-event theorem is proved and show that the transformed object lies in that class. It must preserve or reprove the all-real threshold facts used by the theorem, the relevant finite-event implication, and every complete arithmetic estimate. Real-zero closure under differentiation can help with one of these obligations; it does not restore the original source coefficients.

## Candidate transformations

1. **Differentiation:** exploit the heat-PDE closure, but state the transformed arithmetic source and the theorem's allowed function class. Derivative errors and source symmetries change.
2. **Deflation on the threshold slice:** dividing out repeated roots supports the existing mirror inequalities, but does not automatically define the same homogeneous heat flow at nearby times. Any induced evolution and extra terms need to be derived and paid.
3. **Controlled perturbation:** generic splitting can help local degree theory. A perturbation of coefficients is not the unchanged theta field; a fixed-function contradiction requires a theorem stable in an admissible arithmetic class, with a justified limiting passage.

These are alternatives to assess, not three accepted steps of a proof.

## First task and acceptance

Write one transformation and the exact hypotheses of the candidate double-event result side by side. Audit every hypothesis, including dependence on positivity, evenness, full reflection, square coefficients, physical orientation, time location, and nonvanishing normalizers. State which fact fails rather than declaring all reductions impossible.

For a recursive proposal, specify an integer or other well-founded measure that strictly decreases, a proved base case, and valid transfers at every step. A reduction that changes the problem class without a closure theorem does not pass. Neither does repeating the same unknown sign at higher derivative orders. A useful scoped result can show that a particular transformation fails a named premise or can preserve a restricted set of them.

## Controls and scope

The even quartic threshold control has genuine double events and satisfies generic heat and threshold properties. Therefore any class enlarged enough to include it still needs a distinguishing arithmetic premise. The weighted-square, reflected and Euler controls screen specific lost source conditions using the [program's premise table][program]; their threshold status must be checked individually.

The established index already handles higher orders, and [BW-06](../../06_direct_all_multiplicity/README.md) may bypass a reduction. The deflated hierarchy in [BW-08](../../08_deflated_jet_hierarchy/README.md) is a set of necessary inequalities, not an induction proving their violation. Save a precise reduction theorem or obstruction with its class, rather than reporting a formal differentiation as higher-multiplicity exclusion.
