# Exact moment nonclosure control

Run `python3 check_moment_nonclosure.py`. The standard-library checker
integrates rational polynomials exactly and retains
[moment_nonclosure_record_20261010.json](moment_nonclosure_record_20261010.json).
It checks positive control densities with identical moments through degree
four and different sixth moments. It is not a theta numerical evaluation,
a universal no-go theorem, or a collision certificate.
