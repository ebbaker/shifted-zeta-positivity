# Finite matrix checks

Run `python3 check_matrix_heat.py` in this folder. The standard-library
checker retains [matrix_heat_record_20261010.json](matrix_heat_record_20261010.json)
and checks the exact bivariate determinant and quartic threshold control.
The source hash identifies the checked source; it is not a mathematical
certificate for the genuine theta heat function. No root-tail limit or
genuine collision exclusion is numerically claimed.
