# Reviews

Dated reviews of this investigation's notes and, when one exists, its
manuscript. A review records an assessment as it was made and is not revised
afterwards; revisions it prompts belong in the notes.

No review yet. When one is written it is named `review_<reviewer>_<date>.md`
and, if carried out by a language model, labelled with the model. Such reviews
verify stated derivations and run the accompanying programmes; they do not
constitute refereeing, and their numerical claims carry the same scope
limitations as the repository's own checks.
