\subsection{The current diagnostic}

The orbit-weight investigation has an existing record of 87 passing
controls: 17 exact integer cases and 70 floating diagnostics. The
manuscript integrates those results; it does not claim a new experiment
or numerical proof. Its program and record are linked below, relative
to the manuscript directory:
\begin{itemize}
\item \href{numerics/check_arithmetic_orbit_weights.py}{Orbit-weight diagnostic program}.
\item \href{numerics/records/arithmetic-orbit-weights-20260923.json}{87-case numerical record}.
\item \href{reviews/review_codex_arithmetic_orbit_weights_20260923.md}{Same-assistant mathematical and numerical audit}.
\end{itemize}

The exact controls enumerate primitive residue tuples in dimensions
1, 2 and 3 for moduli 2, 3, 4 and 6, check divisibility-projection
products, and enumerate scalar character phases. These finite checks
do not replace the general algebraic arguments in the text.

The floating controls compare the Euler products with a M\"obius
convolution, a full zeta quotient with its truncated Dirichlet series,
and a differentiated finite Euler product with its prime-power source.
They also check finite-place state masses, local half-density norms,
affinities, native dilation correlations, shift tangents, and the
piecewise pulse-energy calculation. The affinity table in
Section~\ref{sec:norms} retains only compact samples, not a large
generated dataset.

The recorded environment is Python 3.10.0 with mpmath 1.3.0 at
50 decimal digits. Shell sums run through occupation 360, the
Dirichlet comparison through $n=1500$, and the prime table through
100,000. For the comparison at the positive real Laplace parameter
$p=8$, the elementary
bound $0<c_n(\omega)\le n^{\omega-1/2}$ gives, with
$\alpha=p+1/2-\omega>1$,
\begin{equation}
 0\le Z_\omega(p)-\sum_{n\le N}c_n(\omega)n^{-p}
 \le\frac{N^{1-\alpha}}{\alpha-1}.
\end{equation}
Evaluating this proven bound in floating arithmetic does not make the
comparison an interval certificate. No xi-zero table or external
dataset is used. The record stores a SHA-256 program hash, which
establishes file identity rather than correctness.

Earlier suites are separate: the WZW pilot has 72 controls, the direct
arithmetic source 60, the collar 60, Brownian readout 51, modular
scattering 65, and the fractional cusp test 80. Their notes document
their exact scopes. The two earlier general-shift quadrature
implementations were corrected and fully replayed during the modular
test \cite[Section~8]{ModularNote}; the analytical exclusions were
unchanged. Those historical suites have not been rerun merely for
this editorial revision.

\subsection{Research and document provenance}

The principal source of the current argument is \cite{OrbitNote}.
The earlier notes are cited in Section~\ref{sec:previous} so that the
retrospective need not repeat their derivations. The local README and
build record identify the active TeX inputs, delivered PDF, source
notes, numerical records and review. The manuscript compiles from
local TeX inputs; it does not import the parent Wilson--Loewner
manuscript. The milestone index records this live revision without
creating a dated manuscript snapshot.

The coefficient proofs and scoped exclusions are analytical arguments.
The numerical controls do not prove the existence of a causal physical
interface, the full-family unweighted contraction, or RH. The next
construction is the finite-place interface in
Section~\ref{sec:interface}, rather than a numerical search for zeros.
