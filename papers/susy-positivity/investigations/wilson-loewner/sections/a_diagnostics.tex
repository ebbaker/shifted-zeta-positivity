\section{Reproducible diagnostics and controls}\label{app:diagnostics}

The accompanying package contains three Python standard-library
programs and their preserved JSON results. They register 268 finite
cases. Each case records its name, numerical value, comparison
direction, threshold and pass status. Replay requires identical
parameters, case identities and thresholds and a passing result;
small platform-dependent changes in floating values are permitted.
No case uses zeta zeros or infers an arithmetic positivity theorem.

For transparency the Clifford matrices may be generated by five
tensor factors. With $j=0,\ldots,4$ and Pauli matrices $\sigma_i$,
\begin{equation}
 \Gamma_{2j}=\sigma_3^{\otimes j}\otimes\sigma_1\otimes I^{\otimes(4-j)},
 \qquad
 \Gamma_{2j+1}=\sigma_3^{\otimes j}\otimes\sigma_2\otimes I^{\otimes(4-j)}.
\end{equation}
They satisfy the stated Clifford relations. Projector traces are
compared with independent row reduction. Correct triplet assignments
and the allowed orientation supply nonzero controls for the excluded
choices. The adjoint check uses noncommuting Hermitian matrix segments,
so a mistaken reversal of matrix order cannot pass merely because an
abelian example commutes.

The transport checks compare direct variation of an ordered ODE
solution with the integrated insertion formula on smooth matrix
backgrounds, including mesh refinement. The reflected response
checks compare the analytic coefficient with a separately integrated
double integral and check finite Gaussian current Gram matrices.
The flat and ordinary-adjoint cases are positive or zero controls
for the claimed failures. These comparisons support the written
derivations; they do not certify physical supersymmetry transformations,
quantum operator existence, continuum reflection positivity,
all-order Ward identities or a stochastic contour limit.

The standalone manuscript package can be checked with
\begin{quote}\ttfamily\small
python3 validation/drafts.py check --replay
\end{quote}

The auxiliary free-kernel background in Sections~\ref{sec:arithmetic}

refers to this investigation's three programs, not to every calculation
in its parent investigations. Hash and build records establish file
identity and reproducibility, not mathematical correctness.
