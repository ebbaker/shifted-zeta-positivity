# Checks and records

Check programmes here use the standard library only, print JSON to standard
output, and keep a preserved record under [`records/`](records/). All six are
registered in the `CHECKS` dictionary of
[`validation/drafts.py`](../validation/drafts.py) and replayed with the
manuscript: `python3 validation/drafts.py check --replay` re-runs every one of
them and requires byte-identical output, which it does at 1522 cases.

Six programmes, 1522 cases in total, all passing and verified deterministic
across repeated runs.

The fifth programme is an extended copy of the parent investigation's registered
assembly, [`check_contraction_margin.py`](../../loewner/numerics/check_contraction_margin.py),
with exactly one line changed --- a removable $0/0$ in the $k=0$ Jacobi recurrence
coefficient, which bites at $\omega=1$ and nowhere else --- and a new driver. The
assembly itself needed **no** second Blaschke factor: it is built from the partial
fractions of $R_\omega$, which are the same algebra at every $\omega$.

Counts refer to finite test cases, not independent theorems, and no check here
is a positivity certificate.
